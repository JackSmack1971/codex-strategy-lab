# Phase 6 research orchestration

Codex primary is supervisor; Python owns calculations, state and disposition. Classify exploration, registered experiment, review, reporting, capability engineering or ordinary maintenance. Inspect repository identity, trust, ledger status, authorized data and budget. Never elevate trust to fix discovery. Parallelize independent read-only work only where useful; four child threads is a project preference, not proof of effective settings. Degraded single-agent mode must be explicit; never imply independent review.

## Ownership and lifecycle

The supervisor is the exclusive writer of the active research ledger and evidence store, including registration, transitions, freeze, evidence persistence, reconciliation, run_candidate and adjudicate_trial(record_it=True). No transfer protocol is permitted in Phase 6. Quant engineer prepares experiment code, trial inputs and synthetic verification in assigned source scope; no registered dispatch. Other children provide evidence or proposals, not state mutations. Child fixture tests may write their own isolated temporary synthetic stores, never the active research store. One writer per overlapping source worktree; stop and reconcile if an external writer is detected. These are behavioral contracts, not enforced child sandboxes.

1. Register hypothesis, advance REGISTERED → DATA_PENDING → DATA_QUALIFIED using actual qualification evidence; transition to REVIEW_PENDING.
2. Prepare draft preregistration without test access. Independently review exact draft digest and data evidence (methodology and adversarial roles). Verify handoffs and run the existing objection tests on admissible evidence. Material unresolved proposals, missing required provenance or upheld material objections prevent progression. Use BLOCKED where the engine permits; otherwise stop with an unresolved blocker.
3. Supervisor persists verified review bundle and records REVIEW_RECORDED, then freezes the exact reviewed draft (PREREG_FROZEN). A changed draft invalidates review; after a recorded review stop and reconcile legal state rather than invent a transition. Amend only through established engine rules; no retroactive thresholds.
4. Quant engineer hands off implementation, inputs and verification. Check frozen compliance and dispatch prerequisites; supervisor advances EXPERIMENT_PENDING and calls run_candidate synchronously. No overlapping active-ledger writes. Apply the backtest-engineering skill's trusted-caller isolation checks; unknown isolation is unqualified. Never expose genuine reserved file-backed data without independently verified isolation.
5. Independent post-run review compares actual evidence with frozen digest, including leakage, costs, family census and objections. Do not equate this review with a second REVIEW_RECORDED state. Unresolved material findings block completion; preserve evidence and use only legal transitions.
6. Supervisor invokes deterministic adjudication; pipeline may advance EXPERIMENT_COMPLETE before recording ADJUDICATION_RECORDED (state ADJUDICATED). Check all four return fields and replay/readback. Evidence analyst reports only verified recorded disposition as authoritative; provisional diagnostics remain separate. Advance REPORTED only through existing legal evidence rules.

Wait for required handoffs at each barrier, close finished children, resolve contradictions against artifacts. On interruption inspect chain and actual run files; use explicit reconcile-tail/reconcile-trials only after establishing prior writer is inactive, retain every attempted trial and never reuse its ID. No agent may open genuine reserved holdout without qualified isolation. Synthetic qualification is machinery testing only.
