# Behavioral handoff contract (not a native API)

Every delegated task specifies role, task ID, baseline OID, hypothesis/version if applicable, authorized read/write scope, prohibited data, budget, dependencies, required skill and expected output. Worker returns JSON or equivalent structured record with task_id, role, baseline, status (COMPLETE/BLOCKED/INCONCLUSIVE), artifact_refs, findings, checks (command, exit status, artifact), limitations, and next_action. Findings identify artifact, severity, observation, consequence and proposed correction. Domain records use existing research schemas, not this handoff envelope. Do not invent thread IDs; record when observable. Parent validates domain records and checks artifact references and actual results before accepting handoffs. A self-described reviewer is not proof of independence. Reviewer roles are behaviorally read-only; inherited permission boundaries remain in force. Store task evidence in existing work/evidence mechanisms only after validation; do not create competing authoritative memory.
