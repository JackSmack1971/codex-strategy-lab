# Capability Engineering

Read docs/control-plane/capability-lifecycle.md. Establish gap, interface, inputs, effects and negative cases. Obtain scope for implementation; use one writer, focused deterministic tests and independent review. Register only after verification and operator-authorized promotion; candidate tools must not silently enter qualification pathways. Require fresh-session reuse evidence before claiming operational promotion.

Return evidence, limitations, and next safe action. Follow AGENTS.md; this skill grants no authority.
